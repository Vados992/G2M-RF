# Contributing

Changes that affect a confirmatory release must be classified before seeing TEST/EXTERNAL outcomes.

1. Add or update tests first.
2. Explain whether the change is mathematical, numerical, software-only or scientific-protocol changing.
3. Any change to models, thresholds, covariates, split logic or endpoint definitions requires a new locked protocol before new confirmatory data are opened.
4. Never tune a failed gate using the spent TEST/EXTERNAL cohort.
